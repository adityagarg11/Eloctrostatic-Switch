# Electrostatic Actuated Switch Classification using Neural Networks

## Project Overview

This project develops a binary classification model using Artificial Neural Networks (ANNs) to determine whether an electrostatically actuated cantilever beam switch operates within a suitable range.

The classification is based on two input parameters:

* Applied Voltage (V)
* External Force (F)

The model is implemented using TensorFlow/Keras and trained on a synthetic dataset generated using beam deflection equations from solid mechanics.

---

## Problem Statement

Electrostatically actuated switches are commonly used in MEMS (Micro-Electro-Mechanical Systems) and sensing applications. When a voltage is applied, an electrostatic force causes the cantilever beam to deflect. An external force may also act on the beam, affecting its displacement.

The objective of this project is to predict whether the switch will function properly under given operating conditions.

The neural network classifies the switch as:

* **Suitable (1)**
* **Not Suitable (0)**

based on the beam's calculated deflection.

---

## Physical Model

The cantilever beam experiences:

1. A Uniform Distributed Load (UDF) generated by the applied voltage.
2. An External Point Force applied at the free end.

The distributed load is given by:

```text
UDF = 0.1 × V² N/m
```

The total beam deflection is calculated using classical beam theory equations.

---

## Suitability Criteria

A switch is classified as **Suitable (1)** if:

```text
g ≤ Deflection ≤ 6g
```

where:

```text
g = 0.05 m
```

This means:

* Deflection ≥ g → Switch activates successfully.
* Deflection ≤ 6g → Safe operation is maintained.

Otherwise, the switch is classified as:

```text
Class = 0
```

(Not Suitable)

## Neural Network Architecture

The classification model is implemented using TensorFlow/Keras.

### Network Structure

* Input Layer: 2 neurons

  * Voltage (V)
  * External Force (F)

* Hidden Layers:

  * Dense Layers
  * ReLU Activation

* Output Layer:

  * 1 Neuron
  * Sigmoid Activation

### Architecture Diagram

```text
Input Layer (V, F)
          ↓
Dense Layer + ReLU
          ↓
Dense Layer + ReLU
          ↓
Output Layer + Sigmoid
          ↓
Binary Classification
```
