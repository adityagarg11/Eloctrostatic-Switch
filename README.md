Electrostatic Actuated Switch – Classification using Neural Network
Project Overview

This project builds a binary classification model to determine whether an electrostatically actuated beam switch is suitable or not based on:

Applied Voltage (V)
External Force (F)

The model is implemented using Keras and trained on synthetically generated data derived from solid mechanics.

Problem Statement

A cantilever beam is actuated using an electric field generated by an applied voltage. The beam experiences:

A uniform distributed force (UDF) proportional to V
2
An external force (F) applied at the tip

The goal is to predict whether the system behaves properly as a switch.

Suitability Conditions

A design is classified as suitable (1) if:

Deflection ≥ g (switch activates)
Deflection ≤ 6g (safe operation)

Where:

g=0.05m

Otherwise, it is classified as not suitable (0).
